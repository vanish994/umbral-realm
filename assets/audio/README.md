# Áudio do jogo

Arquivos selecionados dos MP3 fornecidos em `docs/`:

- `knife-stab.mp3`: `freesound_gamestudio-rpg-sword-attack-combo-22-388940.mp3`, 0,862 s, MP3 44,1 kHz estéreo, 256 kbps. Reproduzido quando a faca acerta um alvo.
- `revolver-shot.mp3`: `alice_soundz-gun-shot-sound-effect-224087.mp3`, 3,474 s, MP3 44,1 kHz estéreo, 256 kbps. Reproduzido quando o revólver acerta um alvo; uma reprodução anterior é interrompida antes de um novo disparo para evitar caudas sobrepostas.

- Música em runtime, mantida sem duplicação em `docs/wasteland-we-are-all-astronauts-main-version-37037-02-20.mp3`: 140 s, MP3 44,1 kHz estéreo, 320 kbps. Metadados: faixa **Wasteland**, artista **We Are All Astronauts**. Toca em volume baixo e em loop após a primeira interação do jogador, respeitando a restrição de autoplay dos navegadores.

Em 14 de outubro de 2026, o mantenedor confirmou que os dois efeitos de combate estão autorizados para versionamento e distribuição pública como parte do Umbral Realm. Os nomes de origem foram mantidos em `docs/` para preservar a proveniência disponível. A autorização/licença de distribuição da música ainda precisa ser registrada de forma explícita antes de uma publicação comercial.
